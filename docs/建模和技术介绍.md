## 2. KiCad 数据层：PCB 信息提取

### 2.1 核心数据结构

所有元件和网络信息通过 `KiCadUtils` 从 `.kicad_pcb` 文件解析，抽象为以下 dataclass：

```python
@dataclass
class Component:
    """元器件核心数据结构（AABB-based）"""
    id: str                              # 参考编号（如 R1、U2）
    footprint: str                       # 封装名称
    package_type: int                    # 封装类型编码 0-4
    bbox: Tuple[float, float, float, float]  # 当前位置 AABB (x1,y1,x2,y2) mm
    rotation: int                        # 0=0°, 1=90°, 2=180°, 3=270°
    layer: int                           # 0=TOP, 1=BOTTOM
    is_fixed: bool                       # 是否固定（不可移动）
    is_placed: bool                      # 是否已放置
    nets: List[str]                      # 连接的 net_id 列表
    pins: List[Tuple[str, float, float]] # [(pin_number, rel_x, rel_y), ...]

    @property
    def footprint_area(self) -> float:   # 封装面积 mm²
    @property
    def center(self) -> Tuple[float, float]:  # AABB 中心点 mm
```

```python
@dataclass
class Net:
    """网络数据结构"""
    net_id: str                          # 网络名称（如 VCC、GND）
    connections: List[Tuple[str, str]]   # [(comp_id, pin_number), ...]
    is_power: bool                       # 是否电源网络
```

```python
@dataclass
class Board:
    """PCB 板框几何数据结构"""
    bounds: Tuple[Tuple[float, float], Tuple[float, float]]
    # 板框包围盒 ((min_x, min_y), (max_x, max_y)) mm
    # 优先从 Edge.Cuts 层圆弧/线段/多边形顶点计算；
    # 无 Edge.Cuts 时回退为所有元器件 AABB 并集；
    # 两者都无则默认 (0,0)~(100,80) mm

    keepout_zones: List[Tuple[float, float, float, float]]
    # 禁止放置区域的 AABB 列表 [(x1, y1, x2, y2), ...] mm
    # 从 KiCad Zone（IsRuleArea）提取，不支持的区域直接过滤

    margin: float = 1.0                  # 板框内缩距离 mm（BOARD_MARGIN）

    @property
    def valid_area(self) -> Tuple[float, float, float, float]:
        """有效放置区域 (x1, y1, x2, y2) = bounds 内缩 margin"""
    @property
    def diagonal(self) -> float:
        """板框对角线长度 mm（归一化分母）"""
```

> **实际存储**：`board_bounds` 作为 `KiCadUtils` 属性存储 `((min_x,min_y),(max_x,max_y))`，`keepout_zones` 由 `get_keepout_zones()` 按需读取。`valid_area` 和 `diagonal` 在 `PCBLayoutEnv.__init__` 中由 bounds 推导，不是 Board 类的方法。

### 2.2 封装类型编码

通过封装名称关键字自动分类，用于碰撞检测的间距阈值查表：

| 编码 | 封装类型 | 间距阈值 |
|------|----------|----------|

### 3.1 环境初始化

```python
class PCBLayoutEnv(gym.Env):
```

### 3.2 reset() 生命周期

```

  1. load_board() 恢复原始 PCB 状态
  2. 重建 movable_list / fixed_list
  3. placed_list = []，current_step = 0
  4. 构建 decoupling_map / area_ranks 缓存
  5. 返回 (obs, info) — obs 全零（无已放置元件）
```

### 3.3 step() 流程

```python
def step(self, action):
    comp_idx, gx1, gy1, gx2, gy2, rot, lay = action  # 7 元动作

    # C1: 已放置检查
    if component.id in self.placed_list:
        return self._invalid_action("already placed")

    # 网格坐标 → mm 坐标（只定 x1/y1；x2/y2 用目标旋转的真实尺寸精确推导）
    x1 = valid_area[0] + gx1 * CELL_SIZE
    y1 = valid_area[1] + gy1 * CELL_SIZE
    w, h = comp.dims_at_rotation(rot)     # 宽高随旋转交换（不能再用固定 footprint_w/h）
    x2 = x1 + w
    y2 = y1 + h
    # ...

    # AABB 尺寸校验（校验 action 的网格尺寸，容差 = CELL_SIZE）
    if abs(placed_w - w) > CELL_SIZE:
        return self._invalid_action("size mismatch")

    # C2: 碰撞检测（与 fixed_list + placed_list）
    for other in fixed + placed:
        hard, soft = bbox_overlap_penalty(bbox, other.bbox, threshold)

    # C3: 出界检测
    out_of_bounds = out_of_bounds_area(bbox, valid_area)

    # 计算 reward → 更新 placed_list → 判定 done
    # ...
```

## 4. 约束检测：PCBUtils

`PCBUtils` 为纯静态工具类，不持有状态，所有数据由 `PCBLayoutEnv` 传入。

### 4.1 C2：AABB 碰撞检测

```python
@staticmethod
def bbox_overlap_penalty(a, b, spacing_threshold):
    """
    返回 (hard_overlap, soft_spacing):
    - hard_overlap: 物理交叉面积 mm² (>0 表示硬重叠)
    - soft_spacing: 间隙 < threshold 时的连续惩罚值
    """
    dx = min(a[2], b[2]) - max(a[0], b[0])
    dy = min(a[3], b[3]) - max(a[1], b[1])

    if dx > 0 and dy > 0:
        return (dx * dy, 0.0)              # 硬重叠 = 交叉面积

    # 计算间隙和共享边长度
    if dx > 0 >= dy:    gap, edge = -dy, dx
    elif dy > 0 >= dx:  gap, edge = -dx, dy
    else:               return (0.0, 0.0)  # 角对角：零惩罚

    if gap >= spacing_threshold:
        return (0.0, 0.0)                  # 间距充足
    return (0.0, (spacing_threshold - gap) ** 2 * edge)
```

**间距阈值**由两元件封装类型共同决定（取 max），不同封装有不同间距要求（见 §2.2）。

### 4.2 C3：板框约束

```python
@staticmethod
def out_of_bounds_area(bbox, valid_area):
    """返回 bbox 超出 valid_area 的面积 mm²"""
    bbox_area = (x2 - x1) * (y2 - y1)
    intersection = max(0, min(x2, ox2) - max(x1, ox1)) \
                 * max(0, min(y2, oy2) - max(y1, oy1))
    return bbox_area - intersection
```

## 5. 动作空间：5 步自回归分解

### 5.1 设计动机

原始 7 元动作 `(comp_id, x1, y1, x2, y2, rot, lay)` 若展平为单一 Discrete，总动作数 = N × GX × GY × GX × GY × 4 × 2 ≈ **256 亿**（以 50 元件、100×80mm 板为例）。DQN 输出层内存爆炸，且 99.99% 动作非法。

**方案**：将 1 次 7 元决策拆为 5 步顺序决策，每步为独立的小 Discrete 空间。

### 5.2 5 步流程

```
Step 0: comp_id = argmax Q_comp(obs)     ← Discrete(N_movable)
Step 1: gx1     = argmax Q_x1(obs)       ← Discrete(grid_width)
Step 2: gy1     = argmax Q_y1(obs)       ← Discrete(grid_height)
Step 3: rot     = argmax Q_rot(obs)      ← Discrete(4)
Step 4: lay     = argmax Q_lay(obs)      ← Discrete(2)

组装（目标旋转真实尺寸 + ceil 网格占用）：
    w, h = comp.dims_at_rotation(rot)     # 宽高随旋转交换
    gx2 = gx1 + ceil(w / CELL_SIZE)
    gy2 = gy1 + ceil(h / CELL_SIZE)
    action = (comp_idx, gx1, gy1, gx2, gy2, rot, lay) → env.step()
```

x2、y2 由元件 footprint 尺寸自动推导，Agent 无需选择。

### 5.3 Pending 状态机

5 步子步骤的中间状态由 env 内部 pending 变量管理：

```python
def _update_pending(self, action, step_id):
    if step_id == 0: self._pending_comp_idx = action
    elif step_id == 1: self._pending_gx1 = action
    elif step_id == 2: self._pending_gy1 = action
    elif step_id == 3: self._pending_rot = action
    elif step_id == 4: self._pending_lay = action

def _assemble_action(self):
    comp = self.movable_list[self._pending_comp_idx]
    # 目标旋转下真实尺寸，网格占用向上取整（ceil），不能 int() 缩小碰撞框
    w, h = comp.dims_at_rotation(self._pending_rot)
    gx2 = self._pending_gx1 + ceil(w / CELL_SIZE)
    gy2 = self._pending_gy1 + ceil(h / CELL_SIZE)
    return (self._pending_comp_idx, self._pending_gx1, self._pending_gy1,
            gx2, gy2, self._pending_rot, self._pending_lay)
```

### 5.4 动作掩码

**仅 step 0（选元件）使用掩码**，step 1~4 无掩码：

```python
def _build_mask_for_step(self, step_id):
    if step_id == 0:
        # 已放置/固定 → mask=False（硬规则，不可选）
        mask = np.ones(self.N_movable, dtype=bool)
        for i, comp in enumerate(self.movable_list):
            if comp.is_placed or comp.is_fixed: mask[i] = False
        return mask
    # step 1~4: 无掩码，Agent 自行从 reward 学会避开出界
    return None
```

| Step | 掩码？ | 原因 |
|------|--------|------|
| 0 选元件 | ✅ `(N_movable,)` | 已放置元件不可再选，硬规则 |
| 1 选 x1 | ❌ | 出界由 out_of_bounds 惩罚教会 |
| 2 选 y1 | ❌ | 同上 |
| 3 选 rot | ❌ | 原为全 True，从未起作用 |
| 4 选 lay | ❌ | 同上 |

### 6.2 Pending 扩展

5 步自回归期间，观测需携带当前已选的中间状态。在 fixed-slot 后追加：

```python
# pending 槽: [comp_onehot(N_movable), gx1, gy1, rot, lay]
# 总计 = N_movable × 8 + N_movable + 4

def _get_obs_with_pending(self, step_id):
    raw_obs = self._get_obs()              # (N_movable*8,)
    pending_comp = np.zeros(N_movable)
    pending_others = np.zeros(4)

    comp_ok = self._pending_comp_idx >= 0
    if step_id >= 1 and comp_ok:
        pending_comp[self._pending_comp_idx] = 1.0
    if step_id >= 2 and comp_ok:
        pending_others[0] = self._pending_gx1
    # ... step_id >= 3/4/5 同理

    return np.concatenate([raw_obs, pending_comp, pending_others])
```

## 7. Reward 函数

### 7.1 总体公式

```python
reward = 0.0

# ===== 惩罚项 =====
reward -= 1000.0 * total_hard_overlap      # 硬重叠（面积 mm² × 1000）
reward -= 50.0   * total_soft_spacing       # 软间距（连续惩罚）
reward -= W_oob  * total_out_of_bounds      # 出界（curriculum 权重 100→1000）

# ===== 奖励项 =====
# Net 聚合度：同 net 元件越紧密奖励越高
reward += max(0, 1 - avg_dist / board_diagonal) * 1.0

# 拥塞均衡度：网格 net 计数越均匀奖励越高
reward += max(0, 1 - congestion_std / sqrt(N_movable)) * 1.0

# 去耦电容距离：电容靠近 IC 奖励越高
reward += max(0, 1 - dist / 5.0) * 1.0

# 大元件优先：先放大元件奖励更高
reward += max(0, 1 - rank / N_movable) * 1.0

# 完成奖励（渐进式）
# 每成功放置一个元件（无违规）→ 500/N_movable
completion_partial = 500.0 / N_movable
reward += completion_partial

# 最后一个元件放置时补足差额，确保达到 500
if len(placed_list) + 1 == N_movable:
    completion_bonus = 500.0 - completion_partial * N_movable
    reward += completion_bonus
```

出界惩罚权重跨 episode 线性递增，前期宽容、后期严格，每块 PCB 独立计数：

## 8. DQN 网络结构

### 8.1 5-Head 自回归网络

```python
class DQN(nn.Module):
    """Shared Body + 5 个独立输出 Head"""
    def __init__(self, obs_dim, n_movable, grid_w, grid_h):
        # Shared Body: 3 层 MLP
        self.shared = nn.Sequential(
            nn.Linear(obs_dim, 512), nn.ReLU(),
            nn.Linear(512, 256), nn.ReLU(),
            nn.Linear(256, 128), nn.ReLU(),
        )
        # 5 个 Head（每步一个）
        self.head_comp = nn.Linear(128, n_movable)   # Step 0: 选元件
        self.head_x1   = nn.Linear(128, grid_w)       # Step 1: 选 x1
        self.head_y1   = nn.Linear(128, grid_h)       # Step 2: 选 y1
        self.head_rot  = nn.Linear(128, 4)            # Step 3: 选旋转
        self.head_lay  = nn.Linear(128, 2)            # Step 4: 选层
        self._heads = [self.head_comp, self.head_x1,
                       self.head_y1, self.head_rot, self.head_lay]

    def forward(self, obs, step_id):
        x = self.shared(obs)
        return self._heads[step_id](x)
```

每次 forward 只走一个 Head，其他 4 个不在计算图上。梯度只更新 shared Body + 当前 Head。

### 8.2 DQN Agent

```python
class DQNAgent:
    def __init__(self, ...):
        self.q_net = DQN(...)                      # 在线网络
        self.target_net = DQN(...)                  # 目标网络
        self.target_net.load_state_dict(self.q_net.state_dict())

    def select_action(self, obs, mask, step_id, epsilon):
        """epsilon-greedy + 掩码过滤（mask=None 时全合法）"""
        if mask is None:
            # 无掩码：全空间探索/利用
            if random() < epsilon: return randint(0, n_actions-1)
            return self.q_net(obs, step_id).argmax()
        if random() < epsilon:
            return random.choice(valid_indices)     # 探索
        with torch.no_grad():
            q = self.q_net(obs, step_id)
            q[~mask] = -inf                         # 掩码屏蔽
            return q.argmax()                       # 利用
```

### 8.3 Q-Learning 学习更新

```python
def learn(self, batch):
    # batch: (obs, actions, rewards, next_obs, masks, dones, step_ids, next_step_ids)

    # 当前 Q 值：按 step_id 分组走对应 Head
    for sid in range(5):
        idx = (step_ids == sid)
        q_vals[idx] = self.q_net(obs[idx], sid).gather(1, actions[idx])

    # 目标 Q 值：按 next_step_id 路由 target 网络
    # nsid=0 时从 next_obs 提取 placed_flag 构建掩码，屏蔽已放置元件虚高 Q
    # next_step_id = -1 表示终端（无 next Q）
    for nsid in range(5):
        idx = (next_step_ids == nsid)
        next_q = self.target_net(next_obs[idx], nsid)
        if nsid == 0:
            placed = next_obs[idx, :self.n_movable*8][:, ::8]  # slot 第 0 维
            comp_mask = (placed < 0.5)                         # 未放置=可选
            next_q[~comp_mask] = -inf
        target_q[idx] = next_q.max(dim=1)

    # 标准 DQN 目标: r + γ * max Q_target(s', a') * (1 - done)
    target = rewards + gamma * target_q * (1 - dones)
    loss = MSE(q_vals, target)

    loss.backward()
    clip_grad_norm_(max_norm=1.0)
    optimizer.step()
```

### 8.4 5 步 Reward 分配

采样的 5 条 transition 共享 env 返回的 reward，但**仅 step 4（最终步）获得环境 reward**，step 0-3 reward=0：

```python
for i, (s, a, mask, sid) in enumerate(transitions):
    if sid < 4:
        next_s = transitions[i + 1][0]     # 下个子步骤的 obs
        next_sid = sid + 1
        step_done = False
    else:
        next_s = obs_next                   # env 返回的布局 obs
        next_sid = 0 if not done else -1   # -1 = 终端

    step_reward = reward if sid == 4 else 0.0  # 仅最终步有 reward
    buffer.add(s, a, step_reward, next_s, mask, step_done, sid, next_sid)
```

**原因**：若中间步也获得 reward，Bellman 方程中的 γ 会倍乘导致训练不稳定。

## 9. 训练流程

### 9.1 训练循环

```python
class Runner:
    def _run_episode(self, env, agent, buffer, pcb_name):
        epsilon = self._compute_epsilon()              # 指数衰减 (per-PCB)
        env.W_OUT_OF_BOUNDS_CURRENT = self._compute_curriculum_weight()  # 递增

        env.reset()
        done = False
        while not done:
            # ---- 5 步自回归决策 ----
            transitions = []
            for step_id in range(5):
                # 仅 step 0 需要掩码
                mask = env._build_mask_for_step(step_id) if step_id == 0 else None
                obs = env._get_obs_with_pending(step_id)
                action = agent.select_action(obs, mask, step_id, epsilon)
                env._update_pending(action, step_id)
                transitions.append((obs, action, mask, step_id))

            # ---- 组装 7 元动作 → env.step() ----
            full_action = env._assemble_action()
            obs_next, reward, terminated, truncated, _ = env.step(full_action)
            done = terminated or truncated

            # ---- 写入 buffer（5 条共享 reward） ----
            for i, (s, a, mask, sid) in enumerate(transitions):
                next_sid = sid + 1 if sid < 4 else (0 if not done else -1)
                step_reward = reward if sid == 4 else 0.0
                buffer.add(s, a, step_reward, ..., sid, next_sid)

            # ---- 每步 learn（buffer 够 batch 就 BP） ----
            if buffer.is_ready(BATCH_SIZE):
                loss = agent.learn(buffer.sample(BATCH_SIZE))
                if train_steps % 100 == 0:
                    agent.sync_target()              # 同步 target 网络
```

### 9.2 超参数

| 参数 | 值 | 说明 |
|------|-----|------|
| γ (GAMMA) | 0.99 | 折扣因子 |
| ε 衰减 | 1.0 → 0.05 | 指数衰减 ε = 0.05 + 0.95·e^(-4t/Emax) |
| ε 衰减公式 | k=4, Emax=total_episodes | 每块 PCB 独立计数，结束时 ε≈0.067 |
| BATCH_SIZE | 64 | mini-batch 大小 |
| REPLAY_BUFFER_SIZE | 100000 | 经验回放缓冲区 |
| LEARNING_RATE | 1e-4 | Adam |
| TARGET_UPDATE_FREQ | 100 | target 网络同步频率 |
| MAX_STEPS | 2000 | 单 episode 最大环境步数 |
| EARLY_STOP_THRESHOLD | -10000.0 | 累计 reward 早停 |
| CURRICULUM | 0-500 ep | 出界权重 100→1000 |

## 10. 推理流程

### 10.1 纯推理 Demo

支持两种输入模式，使用训练好的模型权重进行推理：

```bash
# 真实 KiCad PCB（推荐）
python scripts/run_inference.py \
  --pcb "data/kicad-native-batch/project/project.kicad_pcb" \
  --model "result/project_ep10000.pt"

# JSON mock 数据（无需 KiCad）
python scripts/run_inference.py \
  --data "data/模拟/pcb_001.json" \
  --model "result/pcb_001_ep1000.pt"
```

**关键参数**：
| 参数 | 说明 |
|------|------|
| `--pcb` | `.kicad_pcb` 文件路径 |
| `--data` | JSON 数据文件（与 `--pcb` 二选一） |
| `--model` | 训练好的 `.pt` 权重（不指定则用随机权重） |
| `--export` | 导出最佳布局为 `.kicad_pcb`（默认自动） |
| `--max-attempts` | 最大尝试 episode 数（默认 500） |
| `--debug` | 输出步骤图、布局图等调试文件 |

**流程**：
1. 加载 PCB 数据 + 训练好的 DQN 权重
2. epsilon=0 纯贪婪推理，反复 episode 直到全部放置或达到最大尝试
3. 追踪 reward 最高的布局快照
4. **重放最佳 episode** 的动作序列，每步生成 `step_NN.png`
5. 导出最佳布局 `best_layout.kicad_pcb`（可用 KiCad 打开检验）
6. 输出 `best_layout.png` + `best_layout_state.json` + `inference_log.txt`

**输出结构**：
```
output/<pcb_name>/
├── step_01.png               # 中间步骤图（逐步增量）
├── step_02.png
├── ...
├── best_layout.png           # 最佳布局可视化
├── best_layout.kicad_pcb     # 导出为 KiCad PCB（可打开检验）
├── best_layout.kicad_pro     # KiCad 项目文件
├── best_layout_state.json    # 完整元件状态（给下游消费）
└── inference_log.txt         # 运行日志
```

> **注意**：随机权重下通常只能放置部分元件。训练收敛后再跑推理才能看到完整布局。
