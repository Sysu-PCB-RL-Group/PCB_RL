## C0：Reset 初始位置为板框外

### C0-1 可移动元件初始位置在板内而非板外

在 reset() 中，将可移动元件初始坐标统一设在板框外部（例如 `x = board_x_min - 100mm`，`y = board_y_max + 100mm`）。判定"在板框外"的标准使用元器件**中心点**：中心点在板框内部 → 视为板内；中心点在板框外部 → 视为板外。同时需确保所有元器件的 AABB 包围盒完全不与板框交叉（即整个元件都在板外）。验证 `-100mm` / `+100mm` 偏移量是否对所有元件尺寸都足够。

## C2：元件不重叠（AABB + 连续惩罚）

### C2-1 间距检测使用中心点距离而非 AABB 包围盒

使用 `fp.GetBoundingBox()` 获取每个元件的 AABB 包围盒（格式 `(x_min, y_min, x_max, y_max)`），计算两包围盒在 X/Y 轴的交叉量 `dx`, `dy`，替代 `np.linalg.norm(center1 - center2)` 中心点距离。仅采用 AABB 矩形包围盒作为元器件边界，不引入多边形轮廓等具体边界。违规重叠采用软硬惩罚分层（见 C2-3）。

### C2-2 违规判定为二值逻辑，无连续梯度

返回连续值而非 bool：

- **硬重叠**：返回交叉面积 `dx * dy`（mm²）
- **软间距**：返回 `(2.0 - gap)² × edge_length`
- **角对角**：当对角距离大于阈值时零惩罚（阈值具体数值待定）

```python
KEEPOUT_SOFT = 2.0
def bbox_overlap_penalty(a, b):
    dx = min(a[2], b[2]) - max(a[0], b[0])
    dy = min(a[3], b[3]) - max(a[1], b[1])
    if dx > 0 and dy > 0:
        return (dx * dy, 0.0)           # 硬重叠面积
    if dx > 0 >= dy: gap, edge = -dy, dx
    elif dy > 0 >= dx: gap, edge = -dx, dy
    else: return (0.0, 0.0)             # 角对角：零惩罚（超出阈值）
    if gap >= KEEPOUT_SOFT: return (0.0, 0.0)
    return (0.0, (KEEPOUT_SOFT - gap)**2 * edge)
```

### C2-3 未区分硬重叠与软间距

分层惩罚权重：

- 硬重叠（物理交叉）：`W_OVERLAP_HARD = 1000.0`
- 软间距（靠近但未交叉）：`W_OVERLAP_SOFT = 50.0`

交叉面积 > 0 → 硬重叠违规；无交叉但间隙 < 2mm → 软间距违规；间隙 ≥ 2mm → 不惩罚。

### C2-4 间距阈值统一且不正确（0.2mm）

阈值改为数组形式，按元器件封装类型索引。默认阈值 0.25mm（IPC-7351B Level B Nominal），封装类型分级如下：

| 封装类型                  |  最小间距  |
| --------------------- | :----: |
| Chip (0402/0603/0805) |  0.2mm |
| SOIC/SOT              | 1.25mm |
| QFP                   |  2.5mm |
| BGA                   |   5mm  |
| IC 通用                 |   2mm  |

### C2-5 reward 使用违规计数而非连续惩罚值

```python
reward -= W_OVERLAP_HARD * total_hard_overlap   # 权重 1000
reward -= W_OVERLAP_SOFT * total_soft_spacing    # 权重 50
```

## C3：元件在板框内 + 板边距（AABB + 连续面积 + 出界控制）

### C3-1 板框检查使用中心点而非 AABB 包围盒

计算元件 AABB 的四角坐标 `(x±w/2, y±h/2)` 是否均在 `valid_area`（板框 1mm 内缩区域）内。

### C3-2 违规判定为二值逻辑，无连续出界面积度量

出界面积 = AABB 总面积 - AABB 与 valid_area 交叉面积。返回连续值（mm²）。出界惩罚权重 `W_OUT_OF_BOUNDS = 1000.0`，与硬重叠惩罚 `W_OVERLAP_HARD` 对齐。

```python
W_OUT_OF_BOUNDS = 1000.0
def out_of_bounds_area(bbox, outline):
    bxmin, bymin, bxmax, bymax = bbox
    oxmin, oymin, oxmax, oymax = outline
    bbox_area = max(0.0, (bxmax-bxmin)) * max(0.0, (bymax-bymin))
    ix = max(0.0, min(bxmax, oxmax) - max(bxmin, oxmin))
    iy = max(0.0, min(bymax, oymax) - max(bymin, oymin))
    return bbox_area - ix * iy
```

### C3-3 无 1mm 板边安全裕度

板框内缩 1mm 后方为有效区域 `valid_area`。基于 IPC-2221A（0.5mm）与多家制造商推荐（1mm）之间的折中。

### C3-4 出界时无训练终止机制

采用模拟退火思路，使用余弦函数 epsilon 衰减来控制出界允许率：

- **前期**（step 少）：允许率高，容忍元件出界犯错
- **后期**（step 多）：允许率快速下降，严格禁止出界
- 不采用一刀切式"出界即终止"，而是渐进收紧

```python
# 余弦衰减：前期近 1，后期近 0
epsilon = cos((steps_done / max_steps) * (pi / 2))
```

### C3-5 推理时无 clamp 安全兜底

推理阶段：将输出坐标 clamp 至 `valid_area` 内。

```python
def clamp_to_board(x, y, w, h, outline, spacing):
    half_w, half_h = w/2, h/2
    x = max(outline["x_min"]+half_w+spacing,
            min(x, outline["x_max"]-half_w-spacing))
    y = max(outline["y_min"]+half_h+spacing,
            min(y, outline["y_max"]-half_h-spacing))
    return x, y
```

## C6：去耦电容距离 + net 聚合度

### C6-1 无去耦电容识别机制

遍历 netlist，对于每个带有 VCC/VDD 引脚的 IC，在其连接的网络上查找电容元件（通过元件 value 或 footprint 中包含 "C" 且为 MLCC 封装识别），建立 `decoupling_map = {ic_ref: [cap_ref, ...]}`。

### C6-2 check_layout_constraints 未检查去耦电容距离

在约束检查函数中新增去耦电容距离检查：对每个 `(ic, cap)` 配对，计算电容到 IC 电源引脚组的最小距离，> 5mm 则记录违规。

### C6-3 reward 中无去耦电容距离奖励

```python
for cap in placed_caps:
    dist = min_pin_to_cap_distance(cap.target_ic, cap)
    reward += max(0, 1 - dist / 5.0) * weight_decoupling
```

### C6-4 netlist 连接信息已缓存但未被利用

直接使用 `kicad_utils.py` 中已缓存的 `self.kicad.nets`（通过 `_cache_nets()` 填充），按网络名称（VCC/VDD/等）匹配 IC 电源引脚与去耦电容的配对关系。

同时在 Reward 中增加 **net 聚合度** 加权项。对于同一 net 的所有元器件（位置用中心点表示），聚合度定义为各元件到 net 中心的平均距离：

```python
def net_aggregation(comp_positions):
    """计算 net 内元器件的聚合度（平均到中心距离）"""
    if len(comp_positions) < 2:
        return 0.0
    xs = [p[0] for p in comp_positions]
    ys = [p[1] for p in comp_positions]
    cx, cy = sum(xs)/len(xs), sum(ys)/len(ys)  # net 中心
    dists = [((x-cx)**2 + (y-cy)**2)**0.5 for x, y in comp_positions]
    return sum(dists) / len(dists)
```

聚合度越小（元件越紧密）→ 奖励越大，以适当权重 `W_NET_AGGREGATION` 加入 Reward。

## S2：HPWL 线长最小化

### S2-1 使用紧凑度而非 HPWL

替换 `calculate_layout_compactness()` 为 `calculate_hpwl()`：

```python
def hpwl_for_net(pad_positions):
    if len(pad_positions) < 2: return 0.0
    xs = [p[0] for p in pad_positions]
    ys = [p[1] for p in pad_positions]
    return (max(xs)-min(xs)) + (max(ys)-min(ys))
```

### S2-2 reward 以紧凑度作为布局质量指标

```python
hpwl = self._calculate_hpwl(netlist, positions)
reward += (initial_hpwl - hpwl) / (initial_hpwl - optimal_hpwl) * weight_hpwl
```

使用相对改进率归一化到 [-1, 1]，使同一组超参数可跨不同 PCB 尺寸通用。

**必须配套实现网络优先级**：电源网络（GND/VCC/VDD/VSS）HPWL 权重 = 0.2，普通信号网络权重 = 1.0。否则 GND 将占 HPWL 总量的 60-80%。

### S2-3 netlist 信息已缓存但未用于线长计算

直接使用 `kicad_utils.py` 中已缓存的 `self.kicad.nets`。对每个网络，通过 `net.connections` 中的 `(ref, pin_number)` 对获取各焊盘坐标，计算 x 极差 + y 极差。

## 环境级架构问题

### A-1 PCBUtils 构造函数参数不匹配

`PCBUtils.__init__()` 需改为接受配置参数，或 `pcb_layout_env.py` 移除传参。

### A-2 get_component_list() 方法不存在

调用方应使用已有的 `get_all_component_states()` 或 `kicad.get_component_list()`。

### A-3 get_netlist_state() 方法不存在

调用方应使用已有的 `get_all_net_states()` 或 `get_net_state(net_id)`。布局阶段"未布线网络数"概念本身不当，参考 A-14。

### A-4 self.config 属性不存在

移除对 `self.config` JSON 的依赖。板框尺寸从 `kicad.get_board_bounds()` 获取，reward 权重直接在代码中定义为常量或在 reset 时从参数文件加载。

### A-5 板框尺寸从未知来源读取

使用 `kicad_utils.py` 中已有的 `get_board_bounds()` 方法获取板框边界 `((min_x, min_y), (max_x, max_y))`。

### A-6 component_constraints 配置不存在

使用 `Component.is_fixed` 属性（由 `fp.IsLocked()` 填入）过滤固定元件，替代 JSON 配置路径。参考 C5-1 方案。

### A-7 动作空间缺少 rotation 和 layer 维度

扩展 action 为 `Tuple(Discrete(N), Discrete(grid_x), Discrete(grid_y), Discrete(4), Discrete(2))`：

- rotation：`θ ∈ {0°, 90°, 180°, 270°}`
- layer：`layer ∈ {TOP, BOTTOM}`

### A-8 观察空间缺少元件元数据

观察空间需扩展，加入元件类型编码、封装尺寸 (w, h)、引脚数、已放置标志、当前元件的网络连接度等信息。

### A-9 无动作掩码机制

在 observation 中提供 0/1 mask 向量（长度 = 动作空间维度）。离散空间中：策略网络 softmax 前，将 mask=0 位置的 logits 设为 `-inf`。连续空间中：动作后检查坐标是否在合法区域内，非法则回退到最近合法位置。

### A-10 run.py 调用不存在的方法 get_all_files()

需在 `PCBJointEnv` 中实现 `get_all_files()` 方法，或修改 Runner 使用已有的文件列表逻辑。

### A-11 run.py 引用未定义的参数 max_episode_step

在 `main.py` 的 `get_config()` 中添加 `parser.add_argument("--max_episode_step", type=int, default=100)`。

### A-12 forbidden_areas 列表始终为空

从 KiCad 自动读取禁止区域：

- 遍历 `fp.Zones()`，调用 `zone.GetIsRuleArea()` 检测封装自带 keepout
- 使用 `pcbnew` API 遍历板级 Zone 对象
- 引入 `rate` 参数（0~1）支持分级禁止（circuit_training blockage 机制）

### A-13 终止条件使用无物理意义的 compactness 阈值

终止条件改为：`len(placed_list) == len(movable_components) and len(violations) == 0`。compactness 概念随着 S2 替换为 HPWL 后自然移除。

### A-14 观察空间中"未布线网络数"概念不当

布局阶段所有网络均未布线，此值恒为总网络数，无信息量。该观察分量应移除或替换为有意义的布局阶段指标（如当前 HPWL 值）。

### A-15 pcb_layout_env.py 中存在大量 UTF-8 编码乱码

将文件重新保存为 UTF-8 编码。乱码来源于文件曾被以错误编码方式打开/保存，需用正确编码重新生成中文注释字符串。
