## 1. 问题的形式化

把"给一块板摆元件"写成一个**有限 MDP**：

```text
· 一块板有 n 个 footprint，**放置顺序事先固定**（见 §5.1）⇒ 一个 episode 恰好 n 步
· s_t：当前局面 = 已放件的位姿 + 当前禁布区 + 状态张量（L / G）+ 标量 piece   （§4）
· a_t：**当前这个件**的（旋转 k, cell i, j），编码 a = k·m² + i·m + j，m = 200   （§5）
· 合法域：a 必须落在 **mask** 内 —— 违规不是"罚分"，而是**根本不可选**；
  若采样侧给出 mask 外的动作，env 直接抛 `EnvActionError`（fail-fast，不静默纠正）
· r_t：见 §6（HPWL 收益 + 离散度收益 + 进度项）
· 终止：放完 n 件 ∨ `L` 经掩膜后全空（并记 `deadlock_kind`：structural / policy / order_locked）
```

三条设计取舍（都有理由，不是习惯）：

```text
① **不选件**：顺序固定 ⇒ 状态/动作维度**跨板统一**（不会出现"某板可动件数不同 ⇒ 网络头数不同"），
   也让"专家库重放/检索键"始终一致（§11.4 的固定顺序契约）
② **掩膜而非罚分**：违规是硬约束 ⇒ 网络**不必学"别违规"**这种稀疏信号；奖励只表达"布局好不好"
③ **离散到 cell**：200×200 画布与板框无关 ⇒ 跨板共用同一张图、同一套网络；粒度损失另有账（§3.4）
```

→ 台账 §6.1、§6.3、§11.4

## 2. 几何模型：从 KiCad 到可计算对象

```text
两级数据：raw（KiCad 的 pcbnew 对象，只读、不修改板）→ 转换（`PcbModel`，训练/建模的唯一事实来源）

四类对象（§2.1~§2.4）：footprint（至少含 1 个 pad 的封装）｜pad（属于 footprint）｜via（含无 net 的）｜
                      禁布区（零 pad 封装的实体外形 ∪ 板轮廓开槽，几何取 AABB）
派生视图：net（`pad 中心`的集合）—— HPWL / σ 的输入
```

**"一个件在哪"用"局部 + 锚点"两点式表示**（这是全栈几何的地基）：

```text
锚点（anchor）   = KiCad 里 footprint 的 `(at X Y)`，就是**旋转中心**
局部几何（θ=0）  = 由 KiCad API **现算**后减掉锚点：footprint 外形取 `GetBoundingHull()`、
                   每个 pad 取 `GetBoundingBox()`（源文件里**没有** AABB 这种数据）
位姿反解         = 板坐标 = 锚点 + R(−θ)·局部     （θ ∈ {0°,90°,180°,270°}）
                   pad 中心另有 `rel_offset`（局部中心）⇒ 任意角都精确
```

⚠️ `rotate_aabb` 是"矩形旋转后**再取外接矩形**"，**只在 90° 倍数时等于真实形状**；源文件里的 45° 类

姿态由 `convert_rotation_index` 归一到 4 档（等距点按数值降级）。

**精度分工**（三层，别混）：判定在**连续 mm**（1 nm）上做；动作**离散到 cell**；cell 尺寸由板框与

200×200 画布共同决定（逐板不同）。还有一层"保守容差" `_EPS`（见 §3.3）。

**离线缓存**：导入需要 KiCad（SWIG API），而训练机没有 ⇒ 把 `PcbModel` 冻结成 `data/model_cache/*.pkl`

（`index.json` 是"哪 16 块板"的唯一事实来源）。守门：dump→load **逐字段/逐位**一致，且缓存命中时

**绝不**回落去读 KiCad。

→ 台账 §1、§2、§4.3、§4.5

## 3. 合法域：违规判定与 `L` 的生成

### 3.1 判定式（7 类，逐条见台账 §3.1~§3.5）

```text
硬重叠 A  pad ↔ pad    ：同层 ∧ 不同 footprint ∧ AABB 相交（gap < 0）；**不看 net**
硬重叠 B  pad ↔ via    ：同层 ∧ AABB 相交 ∧ 双方 netcode≠0 ∧ netcode 不等
硬重叠 C  pad ↔ 禁布区 ：同层（无铜层禁布区两层通用） ∧ AABB 相交 ∧ **排除该禁布区所属 footprint 自己的 pad**
软间距    S1 / S2 / S3 ：与硬重叠三对同条件，但把"相交"换成 `0 ≤ gap < 0.2 mm`
                          （0.2 = `.kicad_pro` 的 netclass clearance，全数据集唯一取值）
出界                   ：footprint 的 pad AABB 越出板框外接矩形（不管 net、不豁免）
```

"同层"用的是 **pad 的导入记录层**（`{F}` / `{B}` / `{F,B}`），不做任何换算；元件**不跨层移动**（动作空间

不含层动作 ⇒ 类型层面堵死"翻面"）。

### 3.2 `L` 怎么"解析式"生成（不逐格判定）

逐格判 160,000 次 `Judge` 是 29~232 秒/步，不可接受。做法：把上述三类违规**全部归结成"锚点空间的

矩形并集"**，用 stamping（矩形外扩 + 前缀和/位移表）批量算出 4 张布尔图 ⇒ 这就是 `L`（合法位置矩阵）。

**同一帧纪律**：`L` / `G` / `mask` 必须由**同一份** `placed` + `keepouts` 算出（禁止混用不同帧的几何）。

### 3.3 与判定器 `Judge` 的一致性（可证 + 可测）

```text
· 方向**保守**：禁区向外扩 `_EPS`、板框允许区向内收 `_EPS` ⇒
  **任何被 `Judge` 判违规的位置，都一定被 `L` 判禁止**（危险方向恒为 0；可证）
· 代价：极少数"gap 恰好 = 0.2"的位置被保守禁掉（可量化，量级 1e-4）
· 可测：**全量穷举** 40,000 格 × 4 旋转 = **160,000 个候选 ↔ `Judge` 双向对拍**（0 不一致）
· 双层校验（运行时）：`L` 快、`Judge` 准；训练档落子前用 `Judge` 复核，不一致 ⇒ 抛 `EnvContractError`
```

### 3.4 一条重要的口径：开槽"随件"（口径 A）

板轮廓里的开槽实际是**元件自带的开槽**（USB 口、定位柱）⇒ 它**属于某个 footprint**，随该件平移/旋转；

**未放置的件，其槽不在板上**。全项目**唯一入口**：`board_state` 的当前局面禁布区（静态禁布区恒在场 +

仅已放件的槽按位姿）。验收：与 KiCad 内孔逐姿态对拍 **偏差 0.000e+00 mm**。

→ 台账 §3、§5.3、§0.6 p

## 4. 状态表示（网络输入）

```text
spatial : float32 (8, 200, 200)         通道序 c = rot·2 + {0: L, 1: G}（rot ∈ 0..3）
piece   : float32 (3,)                  [pad 数, 非电源 net 数, 进度 t/n]，前两个用 log1p 归一化且**不裁剪**
```

**`G`（增益矩阵）的定义**（`env/grid_render.py`）：

```text
s_hpwl = (−ΔHPWL)/D    s_disp = (σ_after − σ_before)/D        D = 板对角线
z_*    = clip((s_* − p5) / (p95 − p5), 0, 1)     ← 4 张表算完后**共用一把标尺**（表从不合并）
G      = 0.7·z_hpwl + 0.3·z_disp ∈ [0,1]（合法格）；非法格 = −inf（**送网络时填 0**）
某分量在池内恒定 ⇒ 该分量给 0.5（防 0/0）；两分量同时恒定 ⇒ G ≡ 0.5 + `degenerate=True`（只作元数据）
```

三个设计点：① **必须归一化**（两分量原始跨度差两个数量级 ⇒ 不归一化则权重形同虚设）；② **共用一把标尺**

且**禁止逐旋转归一化**（各旋转各自归一化会把每张表的最优都拉成 1 ⇒ 跨旋转不可比）；③ `G` 是**解析式**

算出来的（和 `L` 同一套 stamping），不是采样估计。

**为什么状态是 `L + G` 两通道、而不加"占用矩阵 P"**：`L` 已含全部障碍信息（放件只会让 `L` 变小），

`P` 是冗余的；曾考虑、已定论不加。

→ 台账 §5.2、§5.4、§5.5、§5.8

## 5. 动作、顺序与掩膜

### 5.1 固定放置顺序（不选件的前提）

```text
score_t(r) = w·a_norm(r) + (1−w)·c_norm_t(r)          w = 0.7（面积）｜1−w = 0.3（动态连通性）
· a_norm     ：log1p(hull 面积) 在**全部件**上 min-max（静态，整局一次）
· c_t(r)     ：|非电源 net(r) ∩ warm_t|，warm_t = 已放件涉及的 net 集（**每步增长**）
· c_norm_t   ：在**当步剩余候选**上 min-max；电源专属件用"全部 net"兜底
· 平手：面积↓ → pad 数↓ → ref↑（**全序**，防 str 哈希随机化导致跨进程漂移）
性质：**纯函数**（只依赖 netlist + 常量）⇒ 与位置/源布局/策略全部无关 ⇒ 可离线冻结、训练零成本
```

### 5.2 掩膜（每步的候选集）

```text
推理档 / 末件：mask = L
训练档        ：mask = L & lookahead      （结果必然 ⊆ L）
```

**lookahead（单步预测掩膜，**深度 = 1**）**：对当前件的每个候选动作，**假装真放下去**，看**固定顺序的

下一个件**是否仍有至少一个合法格；没有 ⇒ 该动作被 mask。算法三件套：

```text
① 增量压缩：L_next(after) = L_next0 \ (当前件新覆盖的禁区) —— 不重算整张 L（放件只增障碍，单调）
② 平移不变性：冲突只取决于两件的**锚点差** ⇒ 预生成紧凑整数位移表（逐 (k,kf) 懒构建）+ 批量查表
③ 早停与快路径：找到一个存活格即通过；另有"被杀矩形并的外接框 + L_next0 前缀和"的 O(1) 快路径
边界：L_next0 全空 ⇒ **全部 pass**（"下一个件当前就没位置"不是本候选的过错）；末件 ⇒ mask = L
```

→ 台账 §6.2、§6.3

## 6. 目标函数与奖励

```text
HPWL  = Σ_net [ (max_x − min_x) + (max_y − min_y) ]   连接点 = pad 中心；**排除电源/地网**
σ     = sqrt( mean|c|² − |mean c|² )                  c = 每个非电源 net 的 **bbox 中心**（点数 ≥ 2）
r_t   = (−ΔHPWL_t)/H_ref + α·(Δσ_t)/D + β[board]      γ = 1
```

**关键性质与设计**：

```text
· H_ref = 该板**参考（专家）布局**的 HPWL ⇒ "专家完整布局 ≡ −1、空局 ≡ 0"（这就是锚）
· 前两项是【势差】⇒ 一局合计恰好 = [−HPWL_final/H_ref + α·σ_final/D] ⇒ **天然保总量、不可被 game**
· β 是**故意破坏守恒**的【进度项】：β = 1.2 × β_crit(该板)，其中
      β_crit = max_m [ (H_n − H_m)/H_ref − α·(σ_n − σ_m)/D ] / (n − m)    ← 沿**专家**曲线取最大
  含义：**"提前停"必须劣于"把剩下的放完"** ⇒ 这是"HPWL 早停惩罚"的临界值；β 与动作无关
  （件数 = 步序号的确定函数）⇒ 它**不改变任何一步的动作排序**，只压住"少放件占便宜"
· σ 的归一化**只除 D**（σ 是**强度量**：尺度由板尺寸决定，实测 log σ ~ log D 相关 0.95）
· α 的来由：α = (w_σ/w_hpwl) × S，w = 0.3/0.7（人给的语义比例），S = **跨动作 p95−p5 中位之比**
  （实测量纲比）⇒ "每步判别力 HPWL:σ = 7:3"；代价是**整局**两项接近等权（σ 每步差异只占其总推进 ~4%）
```

→ 台账 §7.1、§7.1.1、§7.2、§7.3

## 7. 网络与算法

### 7.1 QNet（输出"Q 图"）

```text
输入：spatial (B,8,200,200) + piece (B,3)
主干：Conv(8→32, 3×3, stride2) → Conv(32→64, stride2) → Conv(64→64)   ⇒ 特征图 50×50（分辨率 ÷4）
融合：piece → MLP(3→32→64) ⇒ **广播逐像素相加**到主干特征（最简注入）
解码：两次 ×2 双线性上采样 + 卷积 ⇒ 回到 200×200
头  ：1×1 卷积 → **4 通道** ⇒ q (B,4,200,200)，与动作张量**同形、零转换**
参数量实测 83,156（CPU 可跑）
```

**为什么输出整张 Q 图**：一次前向就给出全部 160,000 个动作的分数（而不是逐个动作过网络），且与 `mask`

同形 ⇒ 选择只需在 mask 内取 argmax。

### 7.2 Double DQN

```text
y = r + γ·Q_target(s', a*)，  a* = argmax_{a ∈ mask(s')} Q_online(s', a)
（候选集用**目标动作在 mask 内** ⇒ 不会把非法格的 Q 当真值；与"行为策略只在 mask 内探索"同口径）
```

### 7.3 回放：为什么必须"打包"

```text
obs 是整张 200×200 图：spatial float32 = 1.28 MB/步 ⇒ 一条经验（obs + next_obs）**2.56 MB**，
容量 10,000 就是 **25.6 GB** —— 放不下。打包后 **380,025 B/条**：
  L 通道（0/1）→ packbits：20,000 B ｜ G 通道 → uint8：160,000 B ｜ mask(s')：20,000 B ｜ 标量 ~34 B
⇒ 容量 10,000 ≈ 3.80 GB（十进制）
```

### 7.4 训练细节（都可复现）

```text
ε(ep) = 0.1 + 0.8·exp(−ep/2000)        探索**始终只在 mask 内**（uniform over mask）
目标网：每 20 个 episode **硬同步**（按 episode 记数，不按 env 步）
优化器：Adam lr = 1e-4；损失 SmoothL1（Huber）；梯度裁剪 10；batch 32；**每 4 个 env 步**更新一次
种子：固定 seed ⇒ 覆盖 torch / numpy / env.reset（**连网络初始化的随机权重也确定**）
```

→ 台账 §9.2

## 8. 训练循环与评估口径

```text
每局：reset（抽一块板）→ 步内 { act(mask 内 ε-贪心) → env.step → observe → 条件更新 } → 终局
评估：每 50 局跑一次**全 16 板**，**贪心**（explore=False）且**推理档 mask = L** —— 与训练档区分
      （训练用 lookahead 掩膜，评估不用 ⇒ 评估口径 = 真实可执行的策略）
best 判据：**完成度优先**，打平看 `HPWL÷H_ref` 更小（§9 的 ① 是主指标）
```

⚠️ 一个必须知道的量级事实：评估用 `loss` **不能判好坏** —— 它是 TD 误差的平方，量级由 reward 尺度决定

（实测地板 ~0.006）；训练早期就会掉到地板（reward 里 β 那部分是网络可直接算出的确定性成分）。

→ 台账 §9.2

## 9. 评估指标（定义 + 已知弱点）

| 指标 | 技术定义 | 方向 |
|---|---|---|
| ① 完成度 | 已放件数 / n（**只看件数**；`completion.py` 另算面积占比与贡献占比，但**主指标是件数**） | 越高越好 |
| ② HPWL 降低% | (专家 − 模型) / 专家 × 100 | 越大越好 |
| ③ σ 提升% | (模型 − 专家) / 专家 × 100 | 越大越好（与 reward 的 `+α·Δσ` 同向） |
| ④ reward 提升% | (R_模型 − R_专家) / \|R_专家\| × 100，R 与训练**同式** | 越大越好 |

**三个已知弱点**（写在这里是为了别被指标误导）：

```text
① 完成度**没有区分度**：掩膜保证每一步都合法 ⇒ 随机策略也能把 16 板全放完（实测 16/16）
② `HPWL÷H_ref` **语义偏松**：H_ref 是"真实工程师的布局"，它还兼顾我们**没建模**的约束
   （布线/机械/工艺）⇒ "把件聚拢"就能压低 HPWL（推理实测出现过 0.53）⇒ < 1 **不等于**更好
③ α 的"7:3"是**每步判别力**口径 ⇒ 整局上 HPWL 与 σ 接近等权（0.92:1）—— 想改"整局比例"要换口径重算 α
```

→ 台账 §10.2、§7.3

## 10. 技术边界（未建模 ≠ 错）

```text
未建模：真实布线可行性、机械/装配约束、工艺规则、人类惯例、散热
任务口径：**"在合法域内最小化 HPWL+σ"**（口径 A）；专家布局**只作参考基线**，不是标准答案
         （实测"HPWL+σ"无法让专家最优 ⇒ 若要让模型"像专家"，必须引入 §8 的"未来分"机制）
仍留空：§8 专家经验预测（核心机制未敲定）｜本期不做 BC（行为克隆）
已知风险：ε 的衰减尺度偏长（跑满 1000 局仍保留大量探索）⇒ "跑更久"未必更好
```

→ 台账 §8、§11、§12
